## BR-02 modeled decision, MCC and traditional MC/DC

A is nonblacklisted eligible patient with a profile; B is active existing doctor; C uses a nonpast date (tomorrow versus seeded past); D configures a matching period; E seeds an occupied doctor slot using a different patient; F seeds a conflicting start for the acting patient using another doctor. The fixture changes those states independently and uses well-formed input at 10:00. Role, profile absence, input syntax, cutoff and commit failure are separate guards. These are ordered early returns in book_appointment, not a literal compound Boolean expression.

The 64 unique executable cases are preserved in the [original MCC CSV](../../tests/team/evidence/phase2/independent-closure/final-ci/unit/br02-mcc.csv), [original JUnit](../../tests/team/evidence/phase2/independent-closure/final-ci/unit/unit.xml) and [full traditional T/F matrix](../../tests/team/evidence/final-audit/mcc-traditional.csv).
